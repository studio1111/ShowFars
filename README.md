# ShowFars — فیلم و سریال فارسی

سامانهٔ GitHub Actions برای دریافت فایل‌های ویدئویی از لینک‌های مستقیمِ مجاز، تبدیل به سه کیفیت و انتشار مرتب در کانال تلگرام. این پروژه از الگوی worker/dispatcher و پردازش FFmpeg پروژهٔ Animehighbo الهام می‌گیرد، اما منطق انیمه، زیرنویس، ترجمه، Gemini و هرگونه کلید هوش مصنوعی حذف شده است.

> فقط فایل‌هایی را وارد صف کنید که حق دانلود، تبدیل و بازنشر آن‌ها را دارید. این پروژه برای دور زدن ورود، DRM، paywall، محدودیت‌های دسترسی یا حفاظت از لینک‌ها طراحی نشده است.

## امکانات
- صف مستقل برای هر فیلم با شناسهٔ پایدار و جلوگیری از انتشار تکراری.
- دانلود مستقیم HTTPS از میزبان‌های مجاز و کنترل اندازه/نوع فایل.
- سه خروجی MP4: 1080p، 720p و 480p با FFmpeg و H.265؛ صدا به AAC تبدیل می‌شود.
- بررسی سلامت فایل با ffprobe و کنترل موفقیت encode پیش از انتشار.
- انتشار ترتیبی: پوستر/اطلاعات، سپس 1080p، 720p و 480p به‌صورت reply به پست فیلم.
- وضعیت JSON پایدار، retry محدود، گزارش خطا و اجرای زمان‌بندی‌شده.
- تست واحد، بررسی syntax و پاک‌سازی اجراهای Actions با حفظ ۳۰ اجرای تکمیل‌شدهٔ آخر.
- بدون زیرنویس، Gemini، API کلید هوش مصنوعی یا سرویس پولی جداگانه.

## Secrets لازم
در **Settings → Secrets and variables → Actions → Secrets** بسازید:
- `TELEGRAM_BOT_TOKEN`: توکن ربات.
- `TELEGRAM_CHAT_ID`: شناسهٔ کانال یا `@channelusername`.

ربات باید در کانال مدیر و دارای مجوز ارسال پیام باشد. هیچ توکنی را داخل فایل‌ها یا logها قرار ندهید.

## محدودیت مهم حجم تلگرام
نسخهٔ ابری Bot API محدودیت حجم آپلود دارد؛ فایل‌های بزرگ فیلم ممکن است رد شوند. برنامه پیش از ارسال اندازه را بررسی می‌کند و خطای روشن ثبت می‌کند، نه اینکه وانمود کند منتشر شده است. GitHub-hosted runner نیز برای ذخیره‌سازی و پردازش فیلم‌های بلند محدودیت دارد. برای فیلم‌های حجیم باید از روش میزبانی/ارسال مجاز و سازگار با اندازهٔ فایل استفاده شود؛ صرف تنظیم دو Secret این محدودیت‌های پلتفرم را حذف نمی‌کند.

## وضعیت اتصال به Pardeh TV

صفحهٔ عمومی Pardeh کاتالوگ و اطلاعات فیلم را نشان می‌دهد، اما طبق توضیحات خود سایت دانلود به حساب کاربری نیاز دارد و هر عنوان هم لزوماً چند نسخهٔ قابل دانلود ندارد. در این نسخه، کشف خودکار کاتالوگ Pardeh و استخراج لینک دانلودِ حساب‌محور پیاده‌سازی نشده است؛ موتور فقط لینک مستقیم HTTPS مجاز را پردازش می‌کند. لینک صفحهٔ فیلم را به‌جای `source_url` وارد نکنید، چون صفحهٔ HTML فایل ویدئو نیست. برای فعال شدن دانلود خودکار از آن منبع، باید یک روش رسمی و مجاز برای دریافت مستقیم فایل در اختیار پروژه باشد؛ این برنامه ورود، DRM یا محدودیت‌های سایت را دور نمی‌زند.

## افزودن فیلم به صف
فایل `data/movies.json` فهرستی از ورودی‌های مجاز است. نمونه:
```json
[
  {
    "id": "sample-movie-2026",
    "title": "عنوان فیلم",
    "year": 2026,
    "source_url": "https://media.example.org/authorized/movie.mp4",
    "poster_url": "https://media.example.org/poster.jpg",
    "description": "توضیحات فارسی",
    "rights_confirmed": true
  }
]
```
جایگزین کردن دامنهٔ نمونه با لینک واقعی فقط وقتی مجاز است که دانلود و بازنشر آن فایل اجازه داشته باشد. ورودی فاقد `rights_confirmed: true`، لینک HTTPS یا میزبان مجاز منتشر نمی‌شود. فهرست میزبان‌های مجاز در `config.json` است.

## اجرا
- خودکار: workflow هر ۳۰ دقیقه صف را بررسی می‌کند.
- دستی: Actions → **ShowFars Movie Pipeline** → Run workflow.
- برای آزمایش ابتدا متغیر `SHOWFARS_DRY_RUN=true` را فعال کنید. حالت پیش‌فرض dry-run است؛ پس از بررسی مقصد و مجوزها آن را به `false` تغییر دهید.
- گزارش و وضعیت در خروجی workflow ثبت می‌شود؛ فایل ویدئوها بین اجراهای GitHub Actions باقی نمی‌مانند.

## معماری
`app.py` هماهنگ‌کننده است؛ `showfars/` شامل دریافت امن، تبدیل، انتشار و state است. هر فیلم در یک چرخه کامل پردازش می‌شود و سه کیفیت آن قبل از انتشار آماده و اعتبارسنجی می‌شوند. شکست یک ورودی نباید سایر ورودی‌ها را متوقف کند.
